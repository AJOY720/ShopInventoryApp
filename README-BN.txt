SHOP INVENTORY APP - বাংলা নির্দেশনা

এটি একটি offline Android inventory starter app।
ফিচার:
- মুদি / ইলেকট্রনিক্স / মেডিসিন category
- Product add
- Search
- Stock in (product edit করে নতুন stock দেওয়ার সুবিধা পরবর্তী version-এ)
- Sale / Stock out
- Low stock indication
- Purchase/Sale price
- Medicine/Food expiry field
- Local offline storage
- Long press করে product delete

Android Studio-তে project folder খুলে Run চাপুন।
APK বানাতে Build > Build APK(s) ব্যবহার করুন।

নোট: এই ZIP-টি source project। সরাসরি Android ফোনে APK হিসেবে install হবে না; Android Studio দিয়ে APK build করতে হবে।


GITHUB ACTIONS:
এই project-এর .github/workflows/build-apk.yml ফাইলটি GitHub Actions দিয়ে APK build করার জন্য যোগ করা হয়েছে।
Repository-তে files upload করার পর Actions tab থেকে Build Android APK workflow চালানো যাবে।
